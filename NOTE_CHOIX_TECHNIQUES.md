# Technical choices

The solution separates a Next.js frontend from an ASP.NET Core API. The API owns validation, income-bracket selection, and all financial calculations; the browser fetches the input bounds from `GET /api/v1/rules` for pre-validation and presents values returned by the API. This keeps bounds and decimal precision in one API configuration. `ILoanCalculator` isolates the fixed-rate implementation so another credit strategy can be added without changing the fixed-rate calculation. The API is versioned at `/api/v1` and documented in `docs/openapi.yaml`.

Income brackets and input bounds live in `backend/Simu.Api/appsettings.json` and are loaded through ASP.NET configuration with file reload enabled. The bracket's monthly rate is authoritative. For reference inputs K=€100,000, D=360, R=€28,000, the annual rate is 2.50%, monthly rate is 0.208309%, and monthly payment rounds to €395.11. The schedule retains decimal precision during calculation and rounds returned payment, interest, principal, and balance values to cents using midpoint away from zero. Aggregate interest and repayment totals are calculated by the API as well; no financial totals or chart series are derived in the browser. The full 360-row API schedule is compared to the supplied CSV by a unit test. The 19 API unit tests pass and Coverlet reports 100% line coverage for `LoanCalculator`.

The bounded in-memory cache stores complete simulation responses for 15 minutes, with a 10,000-entry size limit. Keys include all request inputs, the start month, and a fingerprint of the rate configuration; changing a bracket therefore produces a new key. This keeps results correct after rate updates and bounds memory use. The request workload is small (at most 360 rows), so this cache is optional and can be removed if usage does not justify it.

The frontend displays all months in twelve-row pages, retains the complete schedule for CSV export, and uses Belgian currency formatting. It displays field-level API validation errors and connection failures. The model does not include insurance, fees, taxes, or variable rates.
